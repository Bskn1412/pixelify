# Documentation content

Edit `docs-data.ts` to change navigation, article metadata, and article blocks.

Supported blocks:
- `paragraph`
- `heading` (include a unique `id`)
- `callout` (`info`, `tip`, `warning`)
- `steps`
- `bullets`
- `code`
- `video` (add official `videoUrl`)
- `table`

The page automatically builds its table of contents from `heading` blocks.
